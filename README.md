# SkyEngine 天工柔性制造仿真与调度平台

SkyEngine 面向柔性制造仿真与调度算法研究，提供网格工厂、机器与 AGV 状态展示、动态扰动、运行指标、日志分析，以及算法训练、超参数探索、测试和回放工作台。
