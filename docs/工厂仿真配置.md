# 工厂仿真配置

工厂采用正方形网格。AGV 每一步可以等待，或移动到上下左右相邻的可通行格；车辆不能同时占据同一位置或相向交换位置。

## 物料站与缓冲

在实例中设置原料点、成品点、装卸时间和机器缓冲容量：

```json
{
  "material_handling_config": {
    "raw_material_source": [0, 0],
    "finished_goods_destination": [19, 19],
    "pickup_dwell_steps": 2,
    "dropoff_dwell_steps": 2,
    "buffer_capacity": 4,
    "machine_buffer_capacities": {"0": 2}
  }
}
```

示例坐标需替换为地图中的实际位置。机器、车辆初始位置与物料站之间须有可通行路径。每个订单也可单独设置 `raw_material_source` 和 `finished_goods_destination`。未设置物料站时，系统在与机器、车辆连通的区域内，按坐标顺序选取可通行非机器格的首格和末格作为原料点和成品点。数据集生成的方案会把设备和物料站放在同一连通区域。

缓冲默认容量为 4，包含等待加工和等待搬走的工件。缓冲满时，卸料车辆会携带工件等待，并可由路径算法安排让行，为取货车辆腾出机口；实际装卸期间车辆保持静止。加工完成后没有位置存放工件时，机器也会保持占用。相邻工序在同一位置时可直接衔接，不需要 AGV 搬运。

订单完成时间包括首道供料、工序间运输、加工、等待和末道成品运输。成品卸货完成后，订单才计为完成。

## 随机波动

实例 `seed` 控制默认回合种子。使用相同实例、种子和动作序列可以重现相同过程；更换回合种子可获得新的加工和故障随机实现。

`processing_time_config.preset` 可选 `none`、`mild_variance`、`moderate_variance`、`high_variance`。后三者的加工倍率区间分别为 0.9–1.1、0.8–1.2、0.6–1.4，平均加工时长保持为名义加工时长。故障由 `exception_config` 配置。

运行状态展示名义加工时长、已加工量、剩余量估计及已停机时间。加工完成后可查看实际用时。车辆故障后停在原地；载货工件留在原车，维修后继续运输。

临时障碍作用于普通可通行道路，不会生成在机器位置或车辆当前占据的位置。指定位置与随机生成均遵循这一规则。
